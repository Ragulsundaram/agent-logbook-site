# Agent Logbook website

The public site for [Agent Logbook](https://github.com/Ragulsundaram/agent-logbook), a free VS Code and Cursor extension for browsing, searching, resuming and measuring your Claude Code and Codex chats.

Live at **https://ragulsundaram.github.io/agent-logbook-site/**

Plain HTML, one stylesheet and a little vanilla JavaScript. No framework, no build step. The hero is a working demo of the extension (`demo.js`); every chat and number in it is made up.

Preview locally:

```
python3 -m http.server 4410
```
