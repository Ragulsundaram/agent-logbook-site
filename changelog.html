Changelog

Every release, newest first.

What's new, what got better and what was fixed. Your editor updates the extension on its own; this is what changed.

  1. 1.4.2Oct 19, 2026Latest

    Right-click to copy

    • FixedRight-clicking in a message opens a menu that copies. Copy takes the selected text, Copy link and Copy path take the link or path under the pointer, Copy code takes a code block, and Copy message takes the whole message. Before, the menu only showed a greyed-out Copy unless text was selected.
  2. 1.4.1Oct 18, 2026

    Newest folders first, and Finder that opens

    • ImprovedFolders are ordered by their latest chat instead of by how many chats they hold, so a folder with today's chats no longer sits below one full of old ones.
    • ImprovedIn a workspace with several folders, every one of them counts as current and stays at the top, the most recently active first.
    • ImprovedMore file names are clickable: zip, tar, dmg, vsix and other archives, Office files, and audio and video files.
    • FixedClicking a file path shows it in Finder by asking macOS directly. Before, the editor's own command could open the file in a tab instead. Cmd/Ctrl-click still opens it in the editor.
    • FixedA relative path is looked up in every folder of the workspace, not only the first.
  3. 1.4.0Oct 18, 2026

    Clickable links, and warnings that come back

    • NewLinks and file paths in messages are clickable. A web address opens in your browser. A file path shows the file in Finder, or opens it in the editor with Cmd/Ctrl held; a folder opens in Finder.
    • ImprovedA dismissed usage warning comes back instead of staying gone for the whole window: when the time it warned about has halved, when it gets more serious (unused, then running out), or when a new window starts. Dismissing it in the sidebar also hides it in Live chats, and the other way round.
    • ImprovedThe sidebar is titled Agent Logbook instead of History.
    • FixedThe folder this window is open on stays at the top of the list after you add a chat to a group or open Settings, instead of dropping below busier folders.
  4. 1.3.2Oct 18, 2026

    Links to this website

    • ImprovedThe store pages and README link to this website, its changelog and the privacy page.
  5. 1.3.1Oct 18, 2026

    Live chats for this window, and security fixes

    • ImprovedLive chats shows the chats in this window's folders by default, with a switch in the Settings tab to show every window.
    • NewA setting to open Agent Logbook in the sidebar when the editor starts, instead of the Explorer. Off by default.
    • FixedSecurity: chat titles, project names and file paths are escaped on the dashboards, and the handover-brief prompt is safely quoted when it has to be typed into a shell.
  6. 1.3.0Oct 17, 2026

    Live chats, and use it or lose it

    • NewLive chats: every running chat on one page, working or waiting for you, with your last ask and its latest reply ready to copy. Cards rise to the top as messages arrive.
    • NewUse it or lose it: a quota bar that is about to reset with plenty left, or on course to run out first, is flagged under the bars, on the live board and in the status bar.
    • NewPanel layouts: chats can sit side by side in the terminal panel, at the bottom or on the right.
    • NewOpen any chat straight into a split, running or not.
    • ImprovedOpening a chat starts as soon as the pointer rests on it, so the click is instant.
    • ImprovedRefresh moved to the panel's title bar.
    • FixedPlacing a chat in a split no longer closes another pane, and the chat running in it.
  7. 1.2.2Oct 15, 2026

    Resume finds the right terminal

    • FixedResume finds a chat's terminal when the editor was opened from the Dock, where it could not see the claude command and opened a second terminal instead.
    • ImprovedLong chats open straight away: the latest messages are drawn first and older ones as you scroll up.
    • ImprovedOpening a chat from a search result is faster.
  8. 1.2.1Oct 15, 2026

    The 1M window, from the start

    • FixedChats on a 1M context model show the 1M window from the start, rather than 200K until they pass it.
  9. 1.2.0Oct 14, 2026

    What each chat costs your laptop

    • NewSee what each running chat costs your laptop: memory and CPU for Claude and every command it started, with a warning when one gets heavy.
    • NewCatch commands Claude left running after a chat ended, and stop them from the panel.
    • ImprovedThe chat footer is grouped into Claude (context, cache, cost) and Laptop (memory, CPU), and lines up when the panel is narrow.
  10. 1.1.1Oct 13, 2026

    A memory leak, fixed

    • FixedA chat with screenshots left a full copy of itself in memory every time it was redrawn, so memory could climb into gigabytes over a long session. Measured on a chat with 277 screenshots, it now stays flat.
  11. 1.1.0Oct 13, 2026

    Chat layouts, and search a hundred times faster

    • NewChat layouts: open chats in a fixed spot of the editor (halves, thirds, a stack or a grid) and move any open chat with a command or the chat list's right-click menu.
    • NewResume straight from a search result.
    • NewA runner shows inside an open chat while Claude is working, and stops the moment it finishes.
    • ImprovedSearch is around a hundred times faster, built on an index instead of re-reading every transcript.
    • ImprovedResume opens without a pause.
    • ImprovedRenaming a chat renames a running session and its terminal tab; tabs follow the chat's title.
    • ImprovedCopied messages keep real bullet and numbered lists in Slack.
    • ImprovedNotices from background agents and other sessions show as notes, with the agent's report, rather than as your messages.
    • ImprovedLive chats redraw only what changed, so the view keeps up with the terminal.
    • FixedA finished chat no longer shows as working.
    • FixedToken and cost counts no longer double-count replies, and sub-agent usage is included.
  12. 1.0.1Oct 6, 2026

    Store links

    • ImprovedHomepage and issue links point to the public project page.
  13. 1.0.0Oct 5, 2026

    First public release

    • NewRead, search and resume Claude Code and Codex sessions, grouped by project.
    • NewSub-agents shown where they were launched, as a tree, each openable as its own thread.
    • NewA dashboard over your whole history: tokens, cost, cache efficiency, models, projects, files, hours.
    • NewPer-chat stats, including context growth and prompt-cache expiry.
    • NewA shareable PNG usage card.
    • NewPlan-usage bars across the top of the panel, chosen in Settings.
    • NewGroups, pins, archive and rename. A rename reaches a session that is running in a terminal.

Nothing of that kind yet.
