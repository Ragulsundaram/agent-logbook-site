Features

Small panel. Lots inside.

The things you reach for after a long day of agent work, each one a click from the chat list.

Search every message

Full text across every transcript, not just titles. Results stream in chat by chat.

Sub-agents as threads

Background agents show where they were launched, with their brief and report, and open as their own chat.

Branch with a brief

Start a fresh chat from an old one with a written handover, instead of dragging the whole context along.

Chats in fixed spots

Halves, thirds, a grid or the terminal panel. Move any chat from the right-click menu.

Laptop resources

Memory and CPU per running chat, plus leftover commands from ended chats, with a Stop button.

A card to share

A PNG of your usage for a day, a week or all time, sized for X and Slack. No project names unless you add them.

Memory and instructions

Read and search the memory notes and CLAUDE.md files your agents load at the start of every session.

Rename everywhere

Rename a chat and the running session and its terminal tab change with it.

Private by default

Your chats stay on your laptop.

Agent Logbook reads the transcript files already on your machine. There's no account, no server of its own and no analytics.

  • Transcripts are read from disk and never uploaded
  • One request of its own: your plan usage, the same one Claude Code makes
  • Deleting a chat moves it to a trash folder; nothing is wiped
  • Branch with a brief runs Claude on your plan, only when you click it

Help

Questions, answered.

Does it upload my chats anywhere?

No. It reads the transcript files on your laptop and keeps its own cache next to them in ~/.claude. There's no account, no server of its own and no analytics. The only request it makes by itself is for your plan usage, explained below.

Why does it read my Claude login?

To draw the quota bars. It asks Anthropic for your current plan usage with the same request Claude Code makes, using the token Claude Code already stored: the macOS Keychain, or ~/.claude/.credentials.json on Linux and Windows. The token is never saved or sent anywhere else.

Which editors does it work in?

VS Code 1.94 or later, and editors built on it: Cursor, Windsurf, VSCodium and the rest. Install from the Visual Studio Marketplace in VS Code, or from Open VSX in the others.

Do I need Claude Code or Codex installed?

It shows the chats they've already saved, so you need at least one of them. Resuming a chat needs claude (or codex) on your PATH.

Is the cost what I actually paid?

No. It's what the same tokens would cost at API list prices. On a Pro or Max plan you pay the plan price, so the number shows how much use you get out of it.

Does it change my chat files?

Only in two ways, both on purpose. Renaming a Claude chat adds a title line to its transcript, which is how Claude Code reads the new name. Deleting a chat moves the file to ~/.claude/trashed-sessions instead of wiping it. Everything else it writes is its own cache and settings. The full list is here.

Does the live board show Codex chats?

Not yet. Codex chats are listed, read, searched and resumed alongside Claude's, but live status (the dots and the board) covers Claude chats for now.

Something's broken. Where do I report it?

Open an issue on GitHub, or email ragulsundaram15@gmail.com. Your editor name and version help.
